# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

## Reporting a Vulnerability

Please report vulnerabilities privately using [GitHub's Security Advisories](https://github.com/OntArc/ALMA/security/advisories/new).

We are committed to acknowledging receipt of any vulnerability report and providing an initial response within **14 days**.
