Contributing to ALMA

Developer Certificate of Origin (DCO)
All contributions submitted via pull requests must be signed off under the Developer Certificate of Origin (DCO). By adding a Signed-off-by line you certify that you have the legal right to submit the contribution under the project license (GPL-3.0).

Sign every commit with git commit -s:

git commit -s -m "Your commit message"

This appends:

Signed-off-by: Your Name <your.email@example.com>

If you forgot to sign off an existing commit, amend it with git commit --amend -s. If a pull request contains multiple commits, each commit must be signed off. If you contribute on behalf of your employer, make sure you are authorized to do so.

The full DCO text is available at: https://developercertificate.org/

为参与 ALMA 做出贡献

开发者原产地证书（DCO）
所有通过拉取请求（pull request）提交的贡献，都必须依照《开发者原产地证书》（Developer Certificate of Origin，DCO）进行签署确认（sign off）。添加一行 Signed-off-by（签署人声明），即表示你确认自己有权依据项目许可证（GPL-3.0）提交该项贡献。

请使用 git commit -s 为每一次提交签署确认：

git commit -s -m "Your commit message"

这会追加一行：

Signed-off-by: Your Name <your.email@example.com>

如果忘记为已有的提交签署确认，可用 git commit --amend -s 补充修正。如果一个拉取请求包含多个提交，则每个提交都必须签署确认。如果你是代表雇主进行贡献，请确认自己已获得相应授权。

完整的 DCO 文本可在此处查看：https://developercertificate.org/
